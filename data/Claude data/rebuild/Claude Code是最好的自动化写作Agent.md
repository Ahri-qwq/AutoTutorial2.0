整个工作流的核心，是一个**两层判断机制**。

**第一层：工作区判断**

AI先判断你的任务属于哪个工作区：

每个工作区有不同的CLAUDE.md，规则不同。

比如，公众号写作需要配图，视频创作不需要。你不能用公众号的规则去处理视频创作任务。

**第二层：任务类型判断**

确定工作区后，AI再判断具体任务类型：

不同任务类型，走不同的流程。

比如，新写作任务需要完整9步流程；而修改已有文章只需要"读取原文 → 理解需求 → 修改"。

**为什么要两层判断？**

因为这样AI就不会"瞎猜"了。

它知道自己在哪个工作区，知道该走哪些步骤，知道哪些步骤可以灵活调整，哪些核心原则不能妥协。

流程可预测，协作就高效。

以公众号写作为例，完整流程是9步。

**为什么要这么做？**

因为AI的训练数据不是最新的。如果不强制搜索，它可能会用过时的信息。
